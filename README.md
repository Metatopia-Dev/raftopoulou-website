# Χριστίνα Ραφτοπούλου - Author Website

A beautiful, responsive static website for the Greek author Χριστίνα Ραφτοπούλου.

## Features

- **Elegant Design**: Sophisticated typography using Playfair Display and Crimson Text fonts
- **Background Image**: Uses the provided `background.jpg` as a full-screen background
- **Responsive Layout**: Works perfectly on desktop, tablet, and mobile devices
- **Interactive Navigation**: Five clickable navigation items with hover effects
- **Modern Effects**: Glassmorphism design with backdrop blur effects
- **Accessibility**: Proper focus states and semantic HTML

## Navigation Items

The website features five navigation bullets in Greek:
- **συστήνομαι** (I introduce myself)
- **υπάρχω** (I exist)
- **γράφω** (I write)
- **διαβάζω** (I read)
- **διδάσκω** (I teach)

## Technical Details

- **HTML5**: Semantic markup with proper Greek language support
- **CSS3**: Modern styling with flexbox, backdrop-filter, and smooth transitions
- **Typography**: Google Fonts integration for elegant typefaces
- **Responsive**: Mobile-first design approach
- **Performance**: Optimized for fast loading

## Usage

Simply open `index.html` in any modern web browser to view the website. The background image (`background.jpg`) should be in the same directory as the HTML file.

## Browser Support

Compatible with all modern browsers including:
- Chrome/Edge
- Firefox
- Safari
- Mobile browsers
